## Unreleased

- The host index now splits story lists and a live focus preview by default: metadata, script/assertions (tutorial reset/action tree), and a cached first frame built outside the update loop. `enter` plays in the right pane; `z` uses the full-size player, and `q`/`esc` returns to the same story. Existing `p` full-size playback and `entry.open` live recording remain (`o` opens live). `index.preview=false` restores the single list and live Enter behavior; the setting is exposed by every host's CLI and TUI.

- The `cell` expect finds a table's current cell where highlights cross: text underlined on a background colour on a row that holds a reverse bar (ochazuke's intersect tone draws the crossing out of the bar) counts, as text underlined in reverse did. A colour's own numbers (`38;2;4;...`) are no longer read as attributes. Test `TestCellText`.

## v0.1.0 (2026-10-29)

First release: the engine, the app seam and the host, moved from ochazuke (lanes L0–L2); requires ochazuke v0.54.0 and oden v0.1.1.

- The host moved in from ochazuke's `cmd/o-story` (lane L2; ochazuke `3a062c0`): `monogatari/host` with `Config` (`Name`, `Prog`, `Apps`, `Stories`, `Dir`, `Getenv`, `Update`), `Main`, `Command` (an oden command named `story` for an app to mount), `Test` (every story as a parallel subtest) and `New`/`Tool`: the commands (run, open, list, history, keep, replay, trim, explore with watch and dedupe, verbs), the catalog shell, the index TUI and the player. Moved, not rewritten; every command and verb keeps its name. Its tests moved with it and run over a test app (`rows`) and `host/testdata/stories`.
- Per-host state: user stories at `$XDG_CONFIG_HOME/NAME/stories` and recordings at `$XDG_DATA_HOME/NAME`, `NAME` being `Config.Name` (default the slug of `Prog`: `mtm story` is `mtm-story`). `DefaultStore` takes the host's name (`DefaultStore(getenv, "o-story")`).
- New catalog nouns `fixture` (list, show, stories) and `application` (list, show, stories, fixtures; `app` is ochazuke's runtime's noun), new verbs `story.copy`, `story.fixture`, `story.recordings`, `recording.delete` (`Store.Delete`), and filters `story.list {app, fixture}`, `fixture.list {app}`, `recording.list {story}`, each relation one handler on both nouns. Story rows carry `app` and `fixture`.
- `verbs --readme` keeps the README's begin marker as written (any `<!-- verbs:begin ... -->`), so each host names its own command there.
- Fixed: a fixture whose `Build` failed after the host made a temp dir panicked (the deferred cleanup closed a nil session); it now returns the fixture's error.
- The engine moved in from ochazuke (lane L1; ochazuke `465906e`, v0.53.0): the story format, `Library` (`Run`, `Resolve`, `Trim`, `Replay`), `Check`, `Golden`, the `Driver` (events, the fake clock, jobs, ticks, reset, restart), `Recorder` and `Store` (the ring of 5, saved recordings), `Derive`/`Minimum`, and `explore` (as `monogatari/explore`). Moved, not rewritten; ochazuke's `story` and `explore` stay frozen and deprecated there for one release.
- The app seam: `App` (`Name`, `Fixtures`, `Fields`, `Expected`), `Fixture` (`Build func(Env) (Built, error)`), `Env` (the story, `Raw`, `Seed`, temp `StateDir`/`ConfigDir`/`FilesDir`, `Now`, size, `Reset`, `NewRuntime`, `Sandbox`, `Field`), `Built` (`Model`, `Program`, `Init`, `Start`, `Close`, `Emit`, `HasPane`, `Writes`, `Snapshot`). `Library.Apps` has no built-in app; `Library.Build`, the driver's reset and restart, `Library.Subject` (explore) and trim's snapshot all go through the story's app and fixture.
- Story fields `app`, `fixture` and `seed`. Top-level fields outside the format are kept in `Story.Fields` (round-tripped by `MarshalJSON`) for the story's app to read; a field its app does not declare in `App.Fields` fails the build. A story naming an app the host lacks fails with `app "NAME" is not in this host (run it with NAME story)`.
- `Session.Program`: an app whose own `tea.Model` wraps the ochazuke model gets every event (`Session.Update`), its view is the frame (`Session.View`, `Frame`), and `Built.Init` runs its `Init` (`Session.Start`). `explore.Subject.Program` does the same for the explorer.
- Changed from ochazuke's `story`: `Build` and `Replay` are `Library` methods (they need the apps); `Session.Writes` is a method; a page's legacy `width`/`height` is refused by the demo app (give the story's); temp dirs are named `monogatari-*`; `Parse` no longer requires a page (the demo app does).

- README rewritten in the family style (logo header, badges, what monogatari is, the tagged tester model, a story example, the family table), with planned features marked *coming in v0.1.0*; the Shiori logo (`assets/logo-light.svg`, `logo-dark.svg`, `icon.svg`).
- New repository (lane L0 of the o-story-for-apps plan): module `github.com/unixsuperhero/monogatari`, AGENTS.md (what monogatari owns and what apps own, the `monogatari` build tag rule, the gate, the release order), README, LICENSE, and a smoke test that drives a model through `github.com/unixsuperhero/ochazuke/keytest`.
- `go.mod` requires ochazuke v0.53.0, the first tag that exports `keytest`; the temporary local `replace` is gone, so a fresh clone builds with `GOWORK=off`.
